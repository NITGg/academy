# Academy Mobile API Reference

Base URL: `http://localhost:8081` (replace with ngrok or production URL)

All authenticated requests require either a **`wstoken`** (Moodle web service token) or a **`token`** (custom API token). These are the same token — generate one per user in Moodle Admin → Server → Web services → Manage tokens.

---

## Authentication

### Get a token
Tokens are generated by an admin. There is no login endpoint in the default setup.  
Alternatively use the Moodle Mobile App service login:

```
POST /login/token.php
Content-Type: application/x-www-form-urlencoded

username=john&password=secret&service=moodle_mobile_app
```

**Response**
```json
{ "token": "abc123...", "privatetoken": "" }
```

Use the returned `token` as `wstoken` in all requests below.

## Standard Moodle Web Service (REST)

All calls go to:
```
GET/POST /webservice/rest/server.php?wstoken={token}&moodlewsrestformat=json&wsfunction={function}
```

### Courses

#### List enrolled courses
```
wsfunction = core_enrol_get_users_courses
userid     = {user_id}
```
**Response** — array of course objects:
```json
[
  {
    "id": 54,
    "shortname": "CS101",
    "fullname": "Introduction to CS",
    "summary": "...",
    "startdate": 1700000000,
    "enddate": 0,
    "visible": 1,
    "courseimage": "https://..."
  }
]
```

#### Get course contents (sections + activities)
```
wsfunction  = core_course_get_contents
courseid    = 54
```
**Response** — array of sections, each with a `modules` array:
```json
[
  {
    "id": 12,
    "name": "Topic 1",
    "modules": [
      {
        "id": 1964,
        "name": "Live Session - Week 1",
        "modname": "jitsi",
        "modplural": "Jitsi",
        "url": "http://localhost:8081/mod/jitsi/view.php?id=1964",
        "visible": 1,
        "availabilityinfo": ""
      }
    ]
  }
]
```

> The `id` field in each module is the **course module id (cm_id)** — use it with the Jitsi token endpoint below.

#### Get a single course
```
wsfunction = core_course_get_courses
options[ids][0] = 54
```

### Users

#### Get current user info
```
wsfunction = core_webservice_get_site_info
```
Returns `userid`, `username`, `fullname`, `userpictureurl`, `sitename`, etc.

#### Get user profile
```
wsfunction  = core_user_get_users_by_field
field       = id
values[0]   = {user_id}
```

### Notifications / Messages

#### Get unread notification count
```
wsfunction = message_popup_get_unread_popup_notification_count
useridto   = {user_id}
```

#### Get messages
```
wsfunction   = core_message_get_messages
useridto     = {user_id}
type         = notifications
```

## Custom Academy API

Base: `/local/academysessions/api.php`  
Auth param: `token={wstoken}`

### Live Sessions — Teacher

#### Create a session
```
GET /local/academysessions/api.php
  ?function=create_session
  &token={wstoken}
  &courseid=54
  &title=Week+1+Live
  &starttime=1750000000       (Unix timestamp)
  &studentids=11,22,33        (comma-separated user IDs)
  &duration=60                (minutes, default 50)
  &jitsiid={jitsi_activity_id}
```
**Response**
```json
{ "status": "success", "data": { "sessionid": 7 } }
```

#### List teacher sessions
```
GET /local/academysessions/api.php
  ?function=get_teacher_sessions
  &token={wstoken}
  &courseid=54                (optional — omit for all courses)
```
**Response**
```json
{
  "status": "success",
  "data": [
    {
      "id": 7,
      "title": "Week 1 Live",
      "start_time": 1750000000,
      "duration": 60,
      "meeting_link": "",
      "students": [ { "id": 11, "fullname": "Ali Hassan" } ],
      "attendance_count": 3
    }
  ]
}
```

#### Update a session
```
GET /local/academysessions/api.php
  ?function=update_session
  &token={wstoken}
  &sessionid=7
  &title=New+Title            (optional)
  &starttime=1750001000       (optional)
  &duration=90                (optional)
```

#### End a session
```
GET /local/academysessions/api.php
  ?function=end_session
  &token={wstoken}
  &sessionid=7
```

#### Delete a session
```
GET /local/academysessions/api.php
  ?function=delete_session
  &token={wstoken}
  &sessionid=7
```

#### Get attendance report
```
GET /local/academysessions/api.php
  ?function=get_attendance
  &token={wstoken}
  &sessionid=7
```
**Response**
```json
{
  "status": "success",
  "data": [
    { "userid": 11, "fullname": "Ali Hassan", "joined_at": 1750000120 }
  ]
}
```

### Live Sessions — Student

#### List upcoming sessions
```
GET /local/academysessions/api.php
  ?function=get_student_sessions
  &token={wstoken}
```
**Response**
```json
{
  "status": "success",
  "data": [
    {
      "id": 7,
      "title": "Week 1 Live",
      "start_time": 1750000000,
      "duration": 60,
      "link_visible": true,
      "meeting_link": ""
    }
  ]
}
```
> `link_visible` is `true` when within 30 min before start and before end time.  
> `meeting_link` is cleared when `link_visible` is `false`.

#### Join a session (records attendance)
```
GET /local/academysessions/api.php
  ?function=join_session
  &token={wstoken}
  &sessionid=7
```
**Response**
```json
{ "status": "success", "data": { "meeting_link": "" } }
```
> After calling this, call the Jitsi token endpoint below to get the JWT.

## Jitsi Video — Get JWT Token to Join

```
GET /mod/jitsi/api_token.php
  ?wstoken={wstoken}
  &id={cm_id}           (course module id from core_course_get_contents)
```

**Response**
```json
{
  "server_url":   "https://your-jitsi-host:8443",
  "room":         "academy_jitsi_1964_a3f2b1c0",
  "jwt":          "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "is_moderator": false,
  "subject":      "Week 1 Live Session",
  "display_name": "Ali Hassan",
  "email":        "ali@example.com"
}
```

**Error responses**
```json
{ "error": "Invalid token" }                        // 401
{ "error": "You are not enrolled in this session" } // 403
{ "error": "Session not open yet" }                 // 403
{ "error": "Session has ended" }                    // 403
```

**Access rules:**
- Students can only join 30 min before start and before end time
- Teachers (`is_moderator: true`) can join any time
- JWT expires 2 hours after generation

### Flutter usage example

```dart
// 1. Get course modules to find the Jitsi cm_id
final contents = await moodleWs('core_course_get_contents', {'courseid': 54});
final jitsiModule = contents
    .expand((s) => s['modules'])
    .firstWhere((m) => m['modname'] == 'jitsi');
final cmId = jitsiModule['id']; // e.g. 1964

// 2. (Student) Call join_session first to record attendance
await customApi('join_session', {'sessionid': 7});

// 3. Get Jitsi JWT
final res = await http.get(Uri.parse(
  '$baseUrl/mod/jitsi/api_token.php?wstoken=$token&id=$cmId'));
final data = jsonDecode(res.body);

// 4. Join with jitsi_meet_flutter_sdk
await JitsiMeet().join(JitsiMeetConferenceOptions(
  serverURL: data['server_url'],
  room:      data['room'],
  token:     data['jwt'],
  configOverrides: {
    'prejoinPageEnabled': false,
    'startWithAudioMuted': true,
    'subject': data['subject'],
  },
  featureFlags: {
    FeatureFlags.recordingEnabled:     data['is_moderator'],
    FeatureFlags.screenSharingEnabled: true,
  },
  userInfo: JitsiMeetUserInfo(
    displayName: data['display_name'],
    email:       data['email'],
  ),
));
```

## Error Format

Custom endpoints return:
```json
{ "status": "fail", "error": "message" }   // api.php
{ "error": "message" }                      // api_token.php
```

Standard Moodle web service returns:
```json
{ "exception": "...", "errorcode": "...", "message": "..." }
```
