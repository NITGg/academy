# 🔢 سباق الحساب

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المدة** | 3–5 دقايق |
| **المهارة** | الجمع والطرح والضرب |
| **السن** | 7–10 سنة |

## الفكرة

مسائل حساب بتيجي ورا بعض، والطفل يختار الإجابة الصح بسرعة.
كل ما يجاوب صح، السباق يكمّل ويسرّع شوية.

## إزاي بتتلعب

1. تظهر مسألة في نص الشاشة
2. تحتيها 3 إجابات
3. الطفل يضغط على الإجابة الصح
4. صح → يكمّل ويجيب نقطة · غلط → المسألة تتعاد بعدين

## مثال

> **٧ + ٥ = ؟**
> `10`  `12`  `13`

## النقاط والشارة

- نقطة لكل إجابة صح
- 🏅 **"سريع الحساب"** — 10 إجابات صح ورا بعض
