# ✅ صح ولا غلط

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المدة** | 2–4 دقايق |
| **المهارة** | معلومات سريعة |
| **السن** | 5–10 سنة |

## الفكرة

جملة بتظهر، والطفل يضغط ✅ أو ❌.
أسهل لعبة في المجموعة — مناسبة جدًا للصغيرين اللي لسه بيقروا بصعوبة.

## إزاي بتتلعب

1. تظهر جملة (مع صورة لو فيه)
2. زرارين كبار: ✅ صح · ❌ غلط
3. الطفل يضغط
4. الإجابة تظهر مع شرح في سطر

## مثال

> **الشمس بتطلع من الغرب**
> ✅ صح   ❌ غلط
> → **غلط!** الشمس بتطلع من الشرق ☀️

## النقاط والشارة

- نقطة لكل إجابة صح
- 🏅 **"مركّز"** — 15 إجابة صح ورا بعض
