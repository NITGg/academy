# 🗺️ خريطة المعرفة

| | |
|---|---|
| **المستوى** | ⭐⭐⭐ كبيرة |
| **المدة** | مفتوحة — رحلة طويلة |
| **النوع** | 🌍 عالم، مش لعبة |
| **السن** | 7–12 سنة |

## ⚠️ دي مش لعبة

**دي خريطة بتجمع الألعاب اللي فوق كلها في مكان واحد.**
معمولة عشان الطفل يحس إن فيه رحلة وهدف، مش مجرد ألعاب متفرّقة.

> 📌 **بتتعمل بعد** ما الألعاب تخلص — مش قبلها.

## الفكرة

خريطة ملوّنة عليها مناطق. كل منطقة فيها مجموعة تحديات،
والتحدي نفسه هو لعبة من اللي فوق.

## إزاي بتشتغل

1. الطفل بيشوف الخريطة وعليها مناطق
2. يضغط على منطقة → تفتح تحدياتها
3. كل تحدي = لعبة من ركن الألعاب
4. يخلّص كل تحديات المنطقة → المنطقة اللي بعدها تتفتح 🔓

## مثال

> **🏝️ جزيرة الأرقام**
> التحدي 1: سباق الحساب
> التحدي 2: صياد الأرقام
> التحدي 3: متجر الحساب
> ✅ خلّصت الجزيرة → **🌋 جبل الحروف** يفتح

## النقاط والشارة

- نجوم لكل منطقة (⭐ لـ ⭐⭐⭐ حسب الأداء)
- 🏅 **"مستكشف"** — فتح كل مناطق الخريطة
