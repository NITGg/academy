# 🏰 رحلة المغامرة

| | |
|---|---|
| **المستوى** | ⭐⭐⭐ كبيرة |
| **المدة** | مفتوحة — رحلة طويلة |
| **النوع** | 🌍 عالم، مش لعبة |
| **السن** | 6–12 سنة |

## ⚠️ دي مش لعبة

**دي قصة بتربط الألعاب ببعض.**
الفرق بينها وبين خريطة المعرفة (23):
الخريطة **مناطق مفتوحة**، والمغامرة **قصة بترتيب**.

> 📌 **بتتعمل آخر حاجة** — بعد ما الألعاب كلها تخلص.

## الفكرة

الطفل بيمشي في عالم بمراحل ورا بعض،
وكل مرحلة فيها تحدي صغير لازم يعدّيه عشان يكمّل القصة.

## المراحل

```
🏠 البيت  →  🌳 الغابة  →  🏰 القلعة  →  🚀 الفضاء
```

## إزاي بتشتغل

1. الطفل يبدأ من البيت مع شخصية بيختارها
2. كل مرحلة فيها تحدي = لعبة من ركن الألعاب
3. يعدّي التحدي → القصة تكمّل والمرحلة اللي بعدها تفتح
4. يجمع في الطريق ⭐ نجوم و 🏅 شارات

## مثال

> **🌳 الغابة**
> "الأرنب تاه ومش عارف طريق بيته!
> ساعده بحل 5 مسائل حساب عشان يلاقي الطريق"
> ✅ → القصة تكمّل ويروح **🏰 القلعة**

## ⚠️ مهم

> المكافآت لازم تكون **مستحقّة ومتوقّعة** —
> "خلّصت المرحلة → أخدت الشارة".
> ❌ ممنوع صناديق أو جوايز عشوائية.

## النقاط والشارة

- نجوم لكل مرحلة
- 🏅 **"مغامر"** — إنهاء الرحلة كاملة
