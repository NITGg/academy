# US-B2B-1-9: View User Activity Report

[← spec index](../README.md) · Area: B2B Administrator · **Status:** Spec

As an admin, I want to view an activity report for each user, so that I can monitor their actions and subscription usage.

## Flow
1. 🔧 Open user management
2. 🔧 Select a user → Open "Activity Report"
3. ⚙️ Display the user's activity details

## Report information
Registration date · last login date · current role · active subscriptions · subscription expiration
dates · courses accessed · B2B memberships · account status · recent important actions.

## Notes
- The admin can filter the report by date.
- Only activities recorded by the system are shown.
- Subscription and payment history remain available even after expiration.
- Sensitive information is visible only to authorized admins.
