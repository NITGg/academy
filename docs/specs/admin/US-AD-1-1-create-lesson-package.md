# US-AD-1-1: Create a Lesson Package

[← spec index](../README.md) · Area: Admin · **Status:** Built · API: [admin-packages](../../api/admin-packages.md) (`create_package`)

As an admin, I want to create a lesson package, so that students can purchase Flexes.

## Flow
1. 🔧 Open package management
2. 🔧 Tap "Create Package"
3. 🔧 Enter package name
4. 🔧 Add description
5. 🔧 Enter number of Flexes
6. 🔧 Enter price
7. 🔧 Set expiration period (duration)
8. 🔧 Activate the package
9. ⚙️ Add creation date and end date
10. ⚙️ Display the package to students

## Notes
- Admin can deactivate a package.
- Deactivating must not remove packages already purchased by students.
