# US-AD-10-1: Assign Certificate to Course

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to assign a certificate template to a course, so that students automatically receive a certificate after completing the course requirements.

## Flow
1. 🔧 Open the course details
2. 🔧 Enable Course Certificate
3. 🔧 Select a certificate template
4. 🔧 Configure the certificate completion requirements
5. ⚙️ Validate the configuration
6. ⚙️ Save the certificate settings

## Notes
- Assigning a certificate is optional.
- Only one active certificate template can be assigned to a course.
- Existing issued certificates are not affected by future configuration changes.
- The certificate is issued automatically once all completion requirements are satisfied.
