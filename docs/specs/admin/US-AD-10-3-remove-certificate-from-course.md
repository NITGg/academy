# US-AD-10-3: Remove Certificate from Course

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to remove the assigned certificate from a course, so that the course no longer issues certificates to students.

## Flow
1. 🔧 Open the course details
2. 🔧 Open the Certificate settings
3. 🔧 Click "Remove Certificate"
4. ⚙️ Display a confirmation message
5. 🔧 Confirm the removal
6. ⚙️ Remove the certificate assignment from the course
7. ⚙️ Save the updated course settings

## Notes
- Removing the certificate only affects future certificate issuance.
- Previously issued certificates remain valid and accessible.
- The course can have no certificate assigned after removal.
- The admin can assign another certificate at any time.
