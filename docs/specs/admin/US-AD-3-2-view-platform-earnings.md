# US-AD-3-2: View Platform Earnings

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to view platform earnings, so that I can track platform revenue from lessons.

## Display (per row)
Completed lesson · teacher name · student name · lesson date · Flex value · platform % · platform earning amount · transaction status.

## Summary
Total platform earnings · total teacher earnings · total consumed Flex value · number of completed lessons.

## Notes
- Only **permanently consumed** Flexes generate platform earnings; returned Flexes do not.
- Earnings use the percentages active **when the Flex was consumed**.
- Filter by date, teacher, transaction status.
