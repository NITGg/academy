# US-AD-3-3: View Package and Flex Reports

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to view package sales, Flex usage, and refund reports.

## Reports
Package sales · packages assigned by admins · purchased & assigned Flexes · consumed Flexes · returned Flexes · expired Flexes · payment refunds · financial reversals.

## Filters
Student · package · transaction type · payment method · date · transaction status.

## Summary
Total package sales · total assigned packages · total Flexes added/consumed/returned · total refunded amount.

## Actions
View transaction details · export CSV.

## Notes
- Online vs external (offline) package payments must be identified separately.
- Returned Flexes and monetary refunds are different transaction types. Exports follow filters.
