# US-AD-7-2: Update a Coupon

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to update a coupon, so that I can modify its behavior.

## Flow
1. 🔧 Open coupon management
2. 🔧 Select a coupon
3. 🔧 Update the discount, limits, or dates
4. 🔧 Save the changes
5. ⚙️ Apply the changes to future usage

## Notes
- Changes do not affect already used coupons.
