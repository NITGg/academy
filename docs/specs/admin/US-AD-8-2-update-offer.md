# US-AD-8-2: Update an Offer

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to update an offer, so that I can modify its behavior.

## Flow
1. 🔧 Open offer management
2. 🔧 Select an offer
3. 🔧 Update the discount, scope, or dates
4. 🔧 Save the changes
5. ⚙️ Apply the changes to future purchases

## Notes
- Changes do not affect past purchases.
- The updated offer applies only moving forward.
