# US-AD-9-2: Update a Program

[← spec index](../README.md) · Area: Admin · **Status:** Spec

As an admin, I want to update a program and its offer, so that I can manage its content and pricing.

## Flow
1. 🔧 Open program management
2. 🔧 Select a program
3. 🔧 Update the name, description, courses list, or price

### Offer update
4. 🔧 Enable / disable the offer
5. 🔧 Update the discount type, value, or dates

### Save changes
6. 🔧 Save the changes
7. ⚙️ Update the program
8. ⚙️ Recalculate the price

## Notes
- Changes apply only to future purchases.
- Existing purchases keep their original price and course access.
- Removing a course does not affect users who already purchased the program.
- Offer updates do not affect previous purchases.
