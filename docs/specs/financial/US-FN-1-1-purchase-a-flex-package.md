# US-FN-1-1: Purchase a Flex Package

[← spec index](../README.md) · Area: Financial · **Status:** Spec

As a student, I want to purchase a Flex package, so that I can use Flexes to book lessons.

## Flow
1. Student → select a package → complete payment
2. ⚙️ Activate package → add Flexes to balance → record the value of each Flex

## Example
Price 20 EGP, 20 Flex → one Flex = 1 EGP.

## Notes
- Flex value = package price ÷ Flex count. Payment recorded in the student's payment history.
- Student-facing purchase flow: [US-PK-1-2](../student/US-PK-1-2-purchase-a-package.md).
