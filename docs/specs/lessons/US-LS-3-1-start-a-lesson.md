# US-LS-3-1: Start a Lesson

[← spec index](../README.md) · Area: Lessons · **Status:** Spec

As a teacher, I want to start a confirmed lesson, so that the system records it has begun.

## Flow
1. 👨‍🏫 Open the confirmed lesson → ⚙️ check the start time has arrived
2. 👨‍🏫 Tap "Start Lesson"
3. ⚙️ Status → `In Progress` → record actual start time → notify student

## Notes
- Only confirmed lessons can start; not before the allowed start time; only the assigned teacher.
- After starting, the teacher can complete the lesson or report student absence.
