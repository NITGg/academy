# US-LS-3-2: Complete a Lesson

[← spec index](../README.md) · Area: Lessons · **Status:** Spec

As a teacher, I want to mark an attended lesson as completed, so that the lesson is recorded and the Flex is used.

## Flow
1. 👨‍🏫 Open the confirmed lesson → conduct it → tap "Complete Lesson"
2. ⚙️ Status → `Completed` → **permanently deduct the reserved Flex** → add to history

## Notes
- Only confirmed lessons can be completed. Teacher can add optional notes.
- Revenue distribution happens here — see [US-FN-1-4](../financial/US-FN-1-4-distribute-lesson-revenue.md).
