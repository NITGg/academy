# US-LS-3-3: Report Student Absence

[← spec index](../README.md) · Area: Lessons · **Status:** Spec

As a teacher, I want to report that a student did not attend, so that the missed lesson is handled correctly.

## Flow
1. 👨‍🏫 Open the confirmed lesson → wait for student → tap "Student Absent"
2. ⚙️ Record absence → status `Student Absent` → apply platform Flex policy → notify student

## Notes
- The Flex may be deducted per platform rules.
- The student may submit a dispute; admin can review disputed cases.
