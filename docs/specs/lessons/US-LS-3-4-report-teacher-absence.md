# US-LS-3-4: Report Teacher Absence

[← spec index](../README.md) · Area: Lessons · **Status:** Spec

As a student, I want to report that a teacher did not attend, so that my Flex can be returned.

## Flow
1. 🎓 Open the confirmed lesson → wait for teacher → tap "Teacher Absent"
2. ⚙️ Record report → status `Teacher Absent` → **return the reserved Flex** → notify teacher and admin

## Notes
- Admin can review the case. Repeated teacher absences may lead to suspension.
