# US-LS-5-1: Update Lesson Time

[← spec index](../README.md) · Area: Lessons · **Status:** Spec

As a student or teacher, I want to request another time for a confirmed lesson, so that it can move to a more suitable time.

## Flow
1. 🎓/👨‍🏫 Open a confirmed lesson → select "Request Time Update" → select another available time
2. ⚙️ Check the time-update deadline → check the new time is available
3. ⚙️ Send the request to the other user → notify them

## Notes
- Either side can request. Must be before the configured deadline.
- Original lesson stays confirmed until the new time is accepted; the student's Flex remains reserved; no additional Flex reserved.
- Only one active time-update request per lesson.
