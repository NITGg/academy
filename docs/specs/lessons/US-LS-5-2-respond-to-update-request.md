# US-LS-5-2: Respond to Update Request

[← spec index](../README.md) · Area: Lessons · **Status:** Spec

As a student or teacher, I want to respond to a time-update request, so that I can accept or reject the requested time.

## Flow
1. 🎓/👨‍🏫 Open the time-update request → review the requested time
2. 🎓/👨‍🏫 Choose: Accept / Reject
3. ⚙️ Update the request → notify the other user

## Results
- Accept → the lesson moves to the new confirmed time
- Reject → the original confirmed time remains unchanged

## Notes
- Requested time must still be available when accepted; original time stays active until accepted.
- Rejecting does not cancel the lesson; the student's reserved Flex is unaffected.
