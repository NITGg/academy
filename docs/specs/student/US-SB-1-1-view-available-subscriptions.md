# US-SB-1-1: View Available Subscriptions

[← spec index](../README.md) · Area: Student (subscriptions) · **Status:** In progress · API: [subscriptions-mobile-guide](../../api/subscriptions-mobile-guide.md) (`get_available_subscriptions`)

As a student, I want to view available subscription plans, so that I can select a suitable plan.

## Flow
1. 🎓 Open the subscriptions screen
2. ⚙️ Display active subscriptions
3. 🎓 Select a subscription
4. ⚙️ Display its details

## Display
Subscription name · price · number of days · description · available courses.
