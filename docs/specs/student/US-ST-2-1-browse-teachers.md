# US-ST-2-1: Browse Teachers

[← spec index](../README.md) · Area: Student · **Status:** Spec

As a student, I want to browse available teachers, so that I can find a suitable teacher.

## Flow
1. 🎓 Open teachers screen → ⚙️ display approved & available teachers
2. 🎓 Filter by subject/specialization → select a teacher → ⚙️ display profile

## Profile may show
Name · profile image · subjects · specializations · experience · available times · rating · reviews · short biography.
