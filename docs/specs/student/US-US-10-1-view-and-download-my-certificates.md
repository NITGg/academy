# US-US-10-1: View & Download My Certificates

[← spec index](../README.md) · Area: Student · **Status:** Spec

As a student, I want to view and download my earned certificates, so that I can keep proof of completing my courses and programs.

## Flow
1. 🎓 Open "My Certificates"
2. ⚙️ Display all issued certificates
3. 🎓 Select a certificate
4. ⚙️ Display the certificate details and preview
5. 🎓 Click "Download PDF"
6. ⚙️ Generate or retrieve the certificate PDF
7. ⚙️ Start the download

## Notes
- Only issued certificates are displayed.
- Certificates are grouped by Course and Program.
- Each certificate displays its issue date and current status.
- Only issued certificates can be downloaded.
- Every certificate includes a unique certificate number and verification code.
- Downloading a certificate does not affect its validity.
