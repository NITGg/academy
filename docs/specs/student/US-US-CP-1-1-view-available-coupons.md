# US-US-CP-1-1: View Available Coupons

[← spec index](../README.md) · Area: Student · **Status:** Spec

As a user, I want to view available coupons, so that I can use them when purchasing.

## Flow
1. 🎓 Open the coupons screen
2. ⚙️ Display the active coupons
3. 🎓 View coupon details

## Display
- Coupon code
- Discount type
- Discount value
- Max discount amount
- Valid dates
- Applicable items

## Related
Coupons are created by an admin in [US-AD-7-1](../admin/US-AD-7-1-create-coupon.md). Applied at
checkout in [US-US-CP-1-2](US-US-CP-1-2-apply-a-coupon.md).
