# US-US-CP-1-3: View My Coupons and Usage History

[← spec index](../README.md) · Area: Student · **Status:** Spec

As a user, I want to view my used coupons, so that I can track my discounts.

## Flow
1. 🎓 Open "My Coupons"
2. ⚙️ Display the used coupons
3. 🎓 View the usage details

## Display
- Coupon code
- Discount applied
- Used date
- Related purchase
- Final paid amount

## Notes
- Only used coupons are shown.
- One-time coupons cannot be reused.
- Multi-use coupons follow their usage limits.
