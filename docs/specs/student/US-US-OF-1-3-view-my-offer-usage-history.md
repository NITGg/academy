# US-US-OF-1-3: View My Offer Usage History

[← spec index](../README.md) · Area: Student · **Status:** Spec

As a user, I want to view offers applied to my purchases, so that I can track my discounts.

## Flow
1. 🎓 Open purchase history
2. ⚙️ Display purchases with applied offers
3. 🎓 View the details

## Display
- Item name (course / package / subscription)
- Original price
- Discount applied
- Final paid amount
- Offer applied date

## Notes
- Only purchases with offers are shown.
- Offer details are linked to each purchase.
- Multi-course offers appear per purchased course.
