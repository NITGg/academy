# US-FN-2-1: Export Teacher Reports

[← spec index](../README.md) · Area: Teacher (financial) · **Status:** Spec

> ⚠️ Duplicate ID — `US-FN-2-1` is also used by [Teacher Earnings Withdrawal](../financial/US-FN-2-1-teacher-earnings-withdrawal.md). Resolve numbering later.

As a teacher, I want to download my reports as PDF or CSV, so that I can keep a record of my lessons, earnings, and withdrawals.

## Flow
1. Open reports → select report type → apply filters → select PDF or CSV
2. ⚙️ Generate and download the report

## Report types
Lesson earnings · withdrawal history · earnings & withdrawals summary · completed lessons · attendance · cancelled lessons.

## Financial report data
Total earnings · available balance · reserved withdrawal amount · total withdrawn amount · Flex value · teacher % · earning amount · withdrawal amount & status.

## Notes
- Teacher exports only their own data; reports follow date/status filters.
- Reversed earnings shown in financial reports.
- Withdrawal reports include pending, approved, rejected, paid requests.
