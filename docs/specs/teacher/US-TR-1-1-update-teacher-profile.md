# US-TR-1-1: Update Teacher Profile

[← spec index](../README.md) · Area: Teacher · **Status:** Built · API: [platform-apis](../../api/platform-apis-postman-guide.md)

As a teacher, I want to update my profile and working hours, so that students see my current information and availability.

## Flow
1. 👨‍🏫 Open profile settings
2. 👨‍🏫 Update personal/teaching information
3. 👨‍🏫 Update available days and working hours
4. 👨‍🏫 Tap "Save Changes"
5. ⚙️ Validate → update profile → display to students

## Notes
- Working hours must not overlap.
- Confirmed lesson times cannot be removed.
- Important profile changes may require admin approval.
