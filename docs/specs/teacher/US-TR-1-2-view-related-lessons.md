# US-TR-1-2: View Related Lessons

[← spec index](../README.md) · Area: Teacher · **Status:** Spec

As a teacher, I want to view my lesson requests and lessons, so that I can respond to students and manage my schedule.

## Flow
1. 👨‍🏫 Open "My Lessons" → ⚙️ display lessons related to the teacher
2. 👨‍🏫 Filter by status → select a lesson
3. ⚙️ Display lesson details (student, date, notes, cancellation reason, attendance report, …)
4. ⚙️ Display actions available for the current status

## Available actions (status-dependent)
Accept request · reject request · suggest another time · accept student's suggested time · cancel a confirmed lesson · start lesson · complete lesson · report student absence · view details.

## Notes
- Teacher sees only their own lessons.
- Pending and waiting-for-teacher requests appear first; upcoming confirmed ordered by date/time.
- Completed/rejected/cancelled remain in history.
