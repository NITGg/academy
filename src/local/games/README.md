## بنك الكلمات

ألعاب الحروف الست كلها تقرأ من قائمة واحدة: مفتاح اللغة `wordbank` في
`lang/<lang>/local_games.php`، سطر لكل كلمة بالشكل `كلمة|إيموجي|تعريف`.
ورفّ المتجر في `shopitems` بالشكل `إيموجي|اسم`. معنى ذلك أن **ترجمة الركن
تترجم محتوى ست ألعاب**، ولا يوجد أي نص لعبة داخل الكود.

> ⚠️ الكلمات بدون تشكيل عمداً: ألعاب الحروف تقسّم الكلمة إلى مربّعات، وعلامة
> التشكيل كانت ستصير مربّعاً مستقلاً.

## البنية

```
index.php              صفحة الركن — كل الألعاب في شبكة كروت
play.php               صدفة اللعب المشتركة لكل الألعاب
classes/registry.php   سجل الألعاب الـ24 + شروط الشارات
classes/progress.php   النقاط والشارات (منطق الأعمال)
classes/external/      الدالة التي يستدعيها المتصفح آخر كل جولة
js/shell.js            الصدفة: الصوت، الـHUD، البداية والنهاية، الحفظ
js/<slug>.js           لعبة واحدة لكل ملف
templates/             hub.mustache و play.mustache
styles.css             تصميم الركن كله
```

القاعدة: **`shell.js` يملك كل ما يجب أن يتصرّف بنفس الطريقة في الـ24 لعبة** —
الصوت، النقاط، كارت النهاية، الحفظ. ملف اللعبة يصف جولته فقط.

## إضافة لعبة جديدة

مثال: اللعبة 03 `math-shop`.

**1.** في [`classes/registry.php`](classes/registry.php) غيّر حالتها إلى
`STATUS_LIVE` وأضف شاراتها:

```php
'math-shop' => [
    'num' => 3, 'emoji' => '💰', 'category' => 'numbers',
    'level' => 2, 'status' => self::STATUS_LIVE,
    'badges' => ['smart-shopper' => ['correct' => 15, 'maxwrong' => 1]],
],
```

**2.** أضف في ملفَّي اللغة (`lang/en` و `lang/ar`):

```php
$string['js_math_shop_ready'] = '...';   // عنوان كارت البداية
$string['js_math_shop_howto'] = '...';   // شرح مختصر
$string['badge_smart_shopper'] = '...';
$string['badgehint_smart_shopper'] = '...';
```

> اسم المفتاح = الـslug بشرطة سفلية بدل الشرطة. `play.php` يبني
> `js_<key>_ready` و `js_<key>_howto` تلقائياً، فالتسمية إلزامية.
> أي مفتاح يبدأ بـ `js_` يصل إلى المتصفح تلقائياً في `api.strings`
> (بدون البادئة).

**3.** أنشئ `js/math-shop.js`:

```js
window.LocalGames.register('math-shop', function (api) {
    return {
        start: function () { /* ابنِ الجولة داخل api.stage */ },
        stop:  function () { /* أوقف أي مؤقت أو حلقة رسم */ }
    };
});
```

**4.** أضف تنسيقاتها في [`styles.css`](styles.css) تحت `.gc-shop`.

**5.** ارفع `version.php` **فقط لو** أضفت جداول أو صلاحيات، ثم:

```bash
docker compose exec moodle php admin/cli/purge_caches.php
```

لا شيء آخر — الكارت يظهر في الركن وحده.

### ⚠️ بعد أي تعديل في `styles.css`

Moodle يدمج `styles.css` الخاص بكل إضافة داخل **ستايل الثيم المُجمَّع**
(لذلك لا يوجد `$PAGE->requires->css()` في `index.php` أو `play.php` — سيكون
تحميلاً مكرراً). النتيجة أن `purge_caches.php` وحده لا يكفي:

```bash
docker compose exec moodle php admin/cli/purge_caches.php
docker compose exec moodle php admin/cli/build_theme_css.php --themes=nit
```

**الترتيب مهم.** `purge_caches` بعد `build_theme_css` يبطل الملف المبني
ويعيدك لنسخة قديمة — أهدرتُ وقتاً في تشخيص «تعديل لم يُطبَّق» وسببه هذا فقط.
دائماً: امسح ثم ابنِ، ولا تمسح بعدها.

### ⚠️ الخصائص التي يقلبها rtlcss

Moodle يمرّر CSS عبر **rtlcss** في اللغات العربية، فيقلب كل خاصية *فيزيائية*
حتى لو كانت نيّتك خلاف ذلك. وقعنا في هذا مرتين:

| الخاصية | ما حدث | الحل |
|---------|--------|------|
| `direction: ltr` على لوحة التحكّم | انقلبت إلى `rtl` فصار زر «شمال» يمين الشاشة | `/* rtl:ignore */` قبل السطر |
| `transform-origin: 0 50%` لشريط التحديد | صارت `100% 50%` فدار الشريط خارج الشبكة | تُضبط من JS — الأنماط السطرية لا يمسّها rtlcss |

القاعدة: لو كان الشيء **تخطيطاً** فاستخدم الخصائص المنطقية ودع rtlcss يعمل؛
ولو كان **جهاز تحكّم أو هندسة محسوبة** فامنعه صراحةً.

## ما تحصل عليه اللعبة من `api`

| العضو | الاستخدام |
|-------|-----------|
| `api.stage` | العنصر الذي تبني اللعبة داخله |
| `api.strings` | كل مفاتيح `js_*` باللغة الحالية |
| `api.fmt(n)` | الرقم بالأرقام العربية الهندية في الواجهة العربية |
| `api.random(a,b)` · `api.pick(arr)` · `api.shuffle(arr)` | مساعدات |
| `api.say(text)` | قراءة النص بصوت عالٍ |
| `api.wordlist` | مفردات أوسع للتحقق فقط (بلا صور ولا تعريفات) |
| `api.correct(msg, points)` | تسجيل إجابة + صوت + رسالة عائمة. `points` اختياري (افتراضي 1) |
| `api.wrong(msg)` | إجابة غلط — الرسالة تبقى ٢.٥ ثانية حتى يلحق الطفل يقراها |
| `api.setLives(n)` | إظهار المحاولات كقلوب |
| `api.setProgress(done, total)` | **إلزامي** — يظهر «٣ / ٥» في الشريط |
| `api.finish(score)` | إنهاء الجولة، الحفظ، وكارت النهاية |

> ⚠️ **`setProgress` ليست اختيارية.** لعبة بلا مؤشّر تقدّم تبدو للطفل بلا نهاية،
> فلا يعرف إن كان توقّفه الآن يضيّع شيئاً. نادِها عند كل زيادة، **لا عند الرسم
> فقط** — وإلا وقف العدّاد عند «١٤ / ١٥» في آخر خطوة.

> ⚠️ `correct` تعدّ **الأحداث** (وعليها تُبنى الشارات) و`score` تعدّ **النقاط**.
> هما نفس الرقم في كل لعبة تعطي نقطة لكل إجابة، ويفترقان في «كوّن الكلمة».

## قواعد ملزِمة (من مستند التصميم)

مذكورة في `docs/Games Doc/README.md` قسم "قواعد كل لعبة". أهمها في الكود:

- **الغلط مش عقاب** — لا رسالة قاسية ولا نسبة مئوية. في `math-race` انتهاء
  الوقت يعيد المسألة للطابور ولا يُنقص شيئاً.
- **محاولات غير محدودة** — "العب تاني" حاضر دائماً في كارت النهاية.
- **صوت مع كل نص** — كل سؤال وكل قاعدة تُقرأ عبر `api.say()`.
- **أزرار كبيرة** — لمس الأصابع الصغيرة، لذلك `.gc-answer` و `.gc-steer`
  بارتفاعات كبيرة.

## بنوك المحتوى

كل محتوى الألعاب في ملفات اللغة، لا في الكود — فترجمة الركن تترجم اللعب نفسه:

| المفتاح | الصيغة | تقرأه |
|---------|--------|-------|
| `wordbank` | `كلمة\|إيموجي\|تعريف` | ٦ ألعاب حروف |
| `wordlist` | كلمات مفصولة بمسافات | كوّن الكلمة (تحقق فقط) |
| `quizbank` | `موضوع\|سؤال\|صح\|غلط\|غلط\|غلط` | **٦ ألعاب أسئلة** |
| `tfbank` | `جملة\|1أو0\|السبب` | صح ولا غلط |
| `whoami` | `إجابة\|إيموجي\|تلميح×٣` | مين أنا؟ |
| `colourbank` | `اسم\|hex` | تحدي الألوان |
| `shopitems` | `إيموجي\|اسم` | متجر الحساب |

المواضيع الأربعة في `quizbank` (`math` · `science` · `language` · `animals`)
هي بالضبط أقسام العجلة في اللعبة ١٥ — تغييرها يغيّر العجلة.

## الشارات

الشرط يُقيَّم **على الخادم** في `progress::submit()`، لا في المتصفح.

| المفتاح | معناه |
|---------|-------|
| `streak` | أطول سلسلة إجابات صح |
| `correct` | عدد الإجابات الصح |
| `maxwrong` | أقصى غلط مسموح |
| `goal` | **هدف اللعبة نفسها** |

`goal` هو ما ترسله اللعبة عبر `api.finish(score, goal)`، ومعناه يختلف بحسبها:
جولات XO المكسوبة، الوصول لآخر كوكب، لوحة ذاكرة داخل ميزانية القلبات، مرحلة
جري بلا فقد قلب. عدّ الإجابات الصح لا يعبّر عن أيٍّ من هذه، واختراع قاعدة لكل
لعبة كان سيضع منطق اللعب داخل الخادم.

تُمنح الشارة مرة واحدة مدى الحياة.

## نقطة الدخول للطفل

على هذا الموقع المدخل هو **أيقونة الترس (gear)** في أعلى الصفحة الرئيسية:
[`lib.php`](lib.php) يضيف بند «ركن الألعاب» إلى عقدة `frontpage` في
settings navigation، وهي العقدة التي يبني منها القالب قائمة الترس. الصلاحية
المفحوصة هي `local/games:play` وهي ممنوحة لدور `user`، أي لكل حساب مسجَّل —
فالطالب يرى الترس ببندٍ واحد حتى لو لم يكن يملك أي صلاحية تحرير للصفحة الرئيسية.

ويمكن إضافة لينك ثابت في النافبار عبر إعداد `custommenuitems` بدون أي تعديل
في الكود:

```
ركن الألعاب|/local/games/index.php
```

## هذه النسخة (academy) تختلف عن الأصل في ثلاثة مواضع فقط

هذه النسخة منقولة من مشروع Games Academy 2026 (Moodle 5.2 + theme_nit) إلى
هذا الموقع (Moodle 3.11 + theme_edumy). ما تغيَّر:

1. **`classes/external/*.php`** — لا يوجد namespace باسم `core_external` قبل
   Moodle 4.2، فأصناف الـexternal API هنا عامة (global) وتُحمَّل من
   `lib/externallib.php`.
2. **`styles.css`** — كتلة المتغيّرات `.local-games` فقط أُعيد توجيهها إلى
   ألوان theme_edumy (بنفسجي فاتح `#6c22a6`) بدل ألوان theme_nit الداكنة. لم
   تُمسّ أي قاعدة أخرى في الملف: كل الألوان تُقرأ من تلك الكتلة.
3. **`lib.php`** — ملف جديد، لا وجود له في الأصل، وهو بند قائمة الترس أعلاه.

منطق الألعاب نفسه (`js/`) والقوالب واللغة وقاعدة البيانات كلها كما هي حرفياً،
حتى يبقى نقل أي إصلاح من المشروع الأصل مجرد نسخ ملف.
